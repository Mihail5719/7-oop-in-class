#### 🤔 Какие решения принимались

**1. Выбор приватных полей (`#`) вместо соглашения `_`**

Рассматривал два варианта:
- `this._name` — старое соглашение (только по договорённости)
- `this.#name` — настоящая приватность (ES2022)

Выбрал `#`, потому что:
- ✅ Реальная защита данных на уровне языка
- ✅ Невозможно обойти извне
- ✅ Современный подход

**2. Переопределение метода `speak()`**

Вместо создания разных методов (`orcSpeak()`, `elfSpeak()`) переопределил один метод `speak()` в каждом подклассе. Это демонстрирует полиморфизм — один интерфейс, разная реализация.

**3. Возврат значений из методов**

Методы `speak()`, `strike()`, `castSpell()` возвращают строку, чтобы её можно было использовать и в консоли браузера, и в веб-интерфейсе.

## 📚 Что изучено в ходе выполнения

### 1. Наследование через `extends` и `super()`

```javascript
class Orc extends Character {
  constructor(name, weapon) {
    super('Орк', name, 'Орочий'); // Вызов конструктора родителя
    this.#weapon = weapon;
  }
}

Ключевые моменты:
extends устанавливает прототипную связь
super() вызывает конструктор родителя
super() должен быть вызван до использования this
2. Переопределение методов

javascript

class Character {
  speak() {
    console.log('Базовая версия');
  }
}

class Orc extends Character {
  speak() { // Переопределение
    console.log('Версия для орка');
  }
}

Важно: сигнатура метода (имя и параметры) сохраняется, меняется только реализация.
3. Полиморфизм

javascript

const party = [orc, elf];
party.forEach(character => character.speak());
// Каждый объект вызывает свою версию метода

avaScript автоматически определяет реальный тип объекта и вызывает соответствующий метод.

🐛 Возникшие проблемы и их решение
Проблема 1: Забыл вызвать super() в конструкторе
Ситуация: При создании new Orc('Громмаш', 'топор') получал ошибку.
Причина: Не вызвал super() в конструкторе Orc.
Решение: Добавил super('Орк', name, 'Орочий') в начало конструктора.
Проблема 2: Приватные поля не наследуются
Ситуация: Пытался обратиться к this.#name в классе Orc.
Причина: Приватные поля доступны только в том классе, где объявлены.
Решение: Использую геттеры this.name вместо прямого доступа к this.#name.
